## Official source and transcription

Source: `project2-MTP-problems-v2026B.docx(1).pdf`, pages 2–3.

For each message, wrapped hexadecimal fragments were joined, message numbering was removed, and the original ordering was preserved. Page footnotes were excluded. No hex digits were intentionally changed.

The source contains ten numbered messages **plus a separately labeled target**. The target differs from C10 and is retained separately. The analysis notebook verifies the dataset against `provenance.json`.

## Simulation output

`simulation.json` is a separate exercise artifact. Re-running Problem 3 replaces this file with a newly generated shared key and corresponding ciphertexts. Do not use the simulation key as a candidate key for the official dataset.

The raw data files use one complete hexadecimal ciphertext per nonempty line. The analysis notebook only reads the official files.
