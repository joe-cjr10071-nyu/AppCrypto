# Ciphertext inputs

The official Many-Time Pad dataset has not yet been added.

Create `ciphertexts.txt` in this folder, with **one complete hexadecimal ciphertext per nonempty line**. Keep the source order. Whitespace within a line is accepted; blank lines are ignored.

Do not include message labels, commas, quotation marks, or `0x` prefixes. If a ciphertext wraps across lines in the source document, join its fragments into one line and document that conversion.

Keep an original source copy when available. Record the source, ciphertext count, message ordering, and any designated target message in `../analysis_notes.md`. The notebook labels the nonempty lines C01, C02, and so on.

If the target is supplied separately, preserve it separately until the assignment clarifies whether it should be included in the comparison list.

The `OTP/` demonstration files are for a separate exercise and should not be used as the assignment dataset.
